# FOCUS - como rodar
1. `pip install -r requirements.txt`
2. `python main.py`
3. Abra `http://127.0.0.1:8000/desktop/telainicialDesktop.html` (ou `/mobile/telainicial.html`).
   Também funciona abrindo os HTML direto da pasta.

Telas: `telas_mobile/` e `telas_desktop/` (geradas por `python tools/gerar_telas.py`; edite os arquivos em `tools/fonte/` para mudar todas de uma vez).
Obs.: renomeie `_init__.py` para `__init__.py` nas pastas antigas (os novos já estão corretos).
