# FOCUS - como rodar
1. `pip install -r requirements.txt`
2. `python main.py`
3. No terminal do VS Code, inicie o servidor Uvicorn:
   `uvicorn main:app --reload`
4. Abra no navegador:
   - **Desktop:** `http://127.0.0.1:8000/desktop/telainicialDesktop.html`
   - **Mobile:** `http://127.0.0.1:8000/mobile/telainicial.html`
   Também funciona abrindo os arquivos HTML direto da pasta.
